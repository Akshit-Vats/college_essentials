# 🛒 E-Commerce Website

## 📌 Overview
This project is a full-stack **E-Commerce Web Application** that allows users to browse products, add items to cart, and place orders.

It includes:
- Frontend (UI for users)
- Backend (API + business logic)
- Database (data storage)

---

## 🚀 Features

### 👤 User Features
- User Registration & Login  
- Browse Products  
- Add to Cart  
- Checkout System  
- Order History  

### 🛍️ Product Features
- Product Listings  
- Categories / Filters  
- Product Details Page  

### ⚙️ Backend Features
- REST API  
- Authentication & Authorization  
- Database Management  
- Order Processing  

---

## 🧠 Tech Stack

### Frontend
- HTML / CSS / JavaScript  
- React 

### Backend
- Flask / Django 

### Database
- PostgreSQL
